avenir-mcp geeft een agent 23 tools, 4 resources en 4 prompts voor je YNAB-plans. Deze
pagina ordent ze naar wat je wilt doen. Elke regel geeft een zin die je tegen de agent kunt
zeggen; de agent kiest de tool.

<Aside type="note">
**L** = alleen lezen, altijd beschikbaar. **S** = schrijven, beschikbaar met
`AVENIR_MCP_WRITE=1`, met voorbeeld en bevestiging. **↺** = ongedaan te maken met
`undo_operation`.
</Aside>

<Aside type="tip" title="Plan of budget?">
YNAB [noemt een budget nu een **plan**](https://web.archive.org/web/20260112213044/https://www.ynab.com/blog/budget-tab-breakdown), en de tools van avenir-mcp ook (`list_plans`,
`plan_id`). Zeg wat je wilt: de agent begrijpt beide en antwoordt met jouw woord. „Mijn
budget voor Restaurants“ betekent nog steeds het bedrag dat aan die categorie is
toegewezen.
</Aside>

## Rondkijken

| Je zegt | Tool | |
|---|---|---|
| *„Welke plans heb ik?“* | [`list_plans`](/avenir-mcp/nl/reference/tools/list-plans/) | L |
| *„Wat staat er op mijn rekeningen?“* | [`list_accounts`](/avenir-mcp/nl/reference/tools/list-accounts/) | L |
| *„Welke categoriegroepen zijn er?“* | [`list_category_groups`](/avenir-mcp/nl/reference/tools/list-category-groups/) | L |
| *„Welke transactie is mijn bon van 86,40 van de 12e?“* | [`find_transactions`](/avenir-mcp/nl/reference/tools/find-transactions/) – op datum, exact bedrag en rekening, gecategoriseerd of niet | L |
| *„Waardoor zit Restaurants deze maand over budget?“* | [`find_transactions`](/avenir-mcp/nl/reference/tools/find-transactions/) – op categorie, gesplitste regels inbegrepen, of op begunstigde, hoe de bank hem ook noemt | L |
| *„Welke facturen moeten vóór de 10e betaald worden?“* | [`list_scheduled_transactions`](/avenir-mcp/nl/reference/tools/list-scheduled-transactions/) – geplande transacties herhaald volgens hun frequentie, inkomend en uitgaand | L |

De plans, rekeningen en categorieën worden ook aangeboden als
[resources](/avenir-mcp/nl/reference/resources-and-prompts/) die je client zonder toolaanroep
aan een gesprek kan koppelen.

## Transacties categoriseren

| Je zegt | Tool | |
|---|---|---|
| *„Haal de nieuwste transacties van mijn bank op.“* | [`import_transactions`](/avenir-mcp/nl/reference/tools/import-transactions/) – wat Import in YNAB doet, meteen toegepast | S |
| *„Wat heeft nog een categorie nodig?“* | [`suggest_categories`](/avenir-mcp/nl/reference/tools/suggest-categories/) – openstaande transacties, met een suggestie als je geschiedenis duidelijk is | L |
| *„Ja, pas dat toe.“* | [`apply_categories`](/avenir-mcp/nl/reference/tools/apply-categories/) – één bevestigde batch | S ↺ |
| *„Zet een vlag op de transacties die ik in YNAB moet nakijken.“* | [`flag_transactions`](/avenir-mcp/nl/reference/tools/flag-transactions/) – een gekleurde vlag, om in YNAB te bekijken | S ↺ |
| *„Splits deze bon: 81,15 boodschappen, 5,25 huishouden.“* | [`split_transaction`](/avenir-mcp/nl/reference/tools/split-transaction/) – één transactie over meerdere categorieën; ongedaan te maken in YNAB, niet hier | S |
| *„Markeer ze als gecontroleerd.“* | [`approve_transactions`](/avenir-mcp/nl/reference/tools/approve-transactions/) – haalt de markering *unapproved* van YNAB weg | S |

Suggesties herkennen een winkelier over zijn bankomschrijvingen heen
(`CB MARKET FRESH FACT 050926 525130******1` en `… 190926 …` zijn dezelfde winkel), leren
inkomend en uitgaand geld apart, en wijzen nooit naar een verborgen categorie.
Handleiding: [Openstaande transacties categoriseren](/avenir-mcp/nl/guides/classify/). Hoe het
werkt: [Suggesties](/avenir-mcp/nl/concepts/suggestions/).

## Kant-en-klare werkstromen

Vier [prompts](/avenir-mcp/nl/reference/resources-and-prompts/#prompts) leiden de agent door
een hele taak. In Claude Code zijn het slash-commando's van de server `avenir-mcp`.

| Prompt | Argumenten | Wat hij doet |
|---|---|---|
| `classify_pending` | plan | suggesties, jouw keuzes, één bevestigde batch, het id om ongedaan te maken |
| `monthly_review` | plan, maand | totalen, wat opvalt, voorgestelde correcties |
| `reconcile` | plan, rekening, banksaldo | het verschil uitgelegd, dan een bevestigde afstemming |
| `plan_next_month` | plan | prognose en aannames, dan de bedragen van volgende maand |

## Ingebouwd

- **Veiligheid:** standaard alleen lezen, bevestiging gekoppeld aan het exacte voorbeeld,
  een lokaal journaal om ongedaan te maken, banktekst als onbetrouwbaar behandeld. Zie
  [Veilig door ontwerp](/avenir-mcp/nl/concepts/safety/).
- **Zuinigheid:** een lokale kopie van je transacties, bijgewerkt met
  delta-synchronisatie; de meeste tools kosten één of twee YNAB-verzoeken. Zie
  [Gegevens en synchronisatie](/avenir-mcp/nl/concepts/data-and-sync/).
- **Duidelijkheid voor agents:** valuta-eenheden, getypeerde uitvoerschema's met een
  beschrijving per veld, paginering, [fouten](/avenir-mcp/nl/reference/errors/) die zeggen wat
  je moet doen.
- **Protocol:** MCP 2026-07-28 en eerdere versies; stdio of streamable HTTP.
