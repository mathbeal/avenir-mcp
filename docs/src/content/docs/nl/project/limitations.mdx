## Bekende beperkingen

| Gebied | Beperking | Omweg |
|---|---|---|
| Bevestigingscodes | in het geheugen bewaard: een herstart van de server vergeet ze | vraag opnieuw om een nieuw voorbeeld |
| Ongedaan maken | beperkt tot de computer waarvan het journaal de operatie heeft vastgelegd; een ongedaanmaking kan niet ongedaan worden gemaakt | de wijziging opnieuw doen |
| `approve_transactions` | wordt meteen toegepast, zonder voorbeeld | het haalt alleen de controlemarkering van YNAB weg |
| `import_transactions` | wordt meteen toegepast, zonder voorbeeld; hier niet ongedaan te maken | het haalt alleen op wat de bank al heeft; verwijder een transactie in YNAB om haar terug te draaien |
| `update_category`, `create_category` | niet ongedaan te maken; de API van YNAB kan geen categorie verwijderen | terug hernoemen; de categorie in YNAB verbergen |
| HTTP-transport | gewoon HTTP, één gedeeld token, geen gebruikersaccounts | houd het op `127.0.0.1`, of gebruik stdio |
| Openbare of gedeelde server | niet ondersteund: geen gebruikersaccounts, en de voorwaarden van YNAB eisen OAuth voor de plans van anderen | ieder draait een eigen avenir-mcp – zie de [juridische informatie](/avenir-mcp/nl/project/legal/) |
| Gesplitste transacties | nooit voorgesteld of opnieuw gecategoriseerd: hun regels dragen de categorieën; `split_transaction` splitst er een, maar de API van YNAB kan een splitsing niet wijzigen of ongedaan maken | wijzig of herstel ze in YNAB |
| Suggesties | hebben een geschiedenis nodig: een winkelier die nooit is gecategoriseerd, krijgt er geen | de agent stelt voor, jij beslist |
| Prognose | trekt de laatste maanden door, plus de geplande transacties van YNAB; een kwartaal- of jaarlijkse kostenpost zonder planning keert volgens haar definitie niet terug | plan haar in YNAB, of geef haar door als `one_offs` |
| Valuta | bedragen worden als getallen getoond, zonder valutasymbool | — |
| Python | 3.12 tot 3.14; 3.15 wacht op een afhankelijkheid (beartype) | — |

## Roadmap

- Van een document naar de planningen van het jaar: de agent leest een belastingaanslag of
  een voorschotnota, en avenir-mcp maakt de planningen en doelen die daarin staan aan of
  werkt ze bij, in één batch met voorbeeld, bevestiging en ongedaanmaking.
- Abonnementen en terugkerende afschrijvingen, alleen lezen: wat je elke maand of elk jaar
  betaalt, en wat het heeft gekost.
- Begunstigden: ze opsommen, en een bankomschrijving hernoemen naar de naam van de winkel,
  met voorbeeld en ongedaan te maken.
- Een transactie wijzigen (datum, bedrag, begunstigde, notitie), zodra besloten is of
  ongedaan maken de oude notitie in het lokale journaal mag bewaren.
- Een bundel `.mcpb` om met één klik te installeren in Claude Desktop.
- Ongedaan maken voor `update_category`.
- De minimale Python-versie verlagen zodra de afhankelijkheden het toelaten.
- De evaluatie draaien via andere clients dan Claude Code, en met lokale modellen.
