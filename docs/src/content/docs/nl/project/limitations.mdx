## Bekende beperkingen

| Gebied | Beperking | Oplossing |
|---|---|---|
| Bevestigingscodes | worden in het geheugen bewaard: bij een herstart van de server gaan ze verloren | vraag opnieuw om een voorbeeld |
| Ongedaan maken | geldt alleen voor de computer waarop de bewerking in het journaal is vastgelegd; het ongedaan maken zelf kan niet ongedaan worden gemaakt | voer de wijziging opnieuw uit |
|  `approve_transactions`| wordt onmiddellijk toegepast, zonder voorbeeld | hiermee wordt alleen de controlevlag van YNAB gewist |
|  `import_transactions`| wordt onmiddellijk toegepast, zonder voorbeeldweergave; kan hier niet ongedaan worden gemaakt | het haalt alleen de gegevens op die de bank al heeft; verwijder een transactie in YNAB om deze terug te draaien |
| `update_category`,  `create_category`| kan niet ongedaan worden gemaakt; de API van YNAB kan geen categorie verwijderen | hernoem de categorie terug; verberg de categorie in YNAB |
| `rename_payee` | hernoemt één begunstigde per keer; de API van YNAB kan er geen twee samenvoegen, dus een naam die een andere begunstigde al heeft wordt geweigerd | hernoem ook de andere labels van de winkel, of voeg de begunstigden samen in YNAB |
| HTTP-transport | gewone HTTP, één gedeeld token, geen gebruikersaccounts | laat het ingeschakeld`127.0.0.1`, of gebruik stdio |
| Openbare of gedeelde server | niet ondersteund: geen gebruikersaccounts, en de voorwaarden van YNAB vereisen OAuth voor abonnementen van anderen | elke persoon draait zijn eigen avenir-mcp — zie de [juridische kennisgeving](/avenir-mcp/project/legal/) |
| Gesplitste transacties | nooit voorgesteld of gehercategoriseerd: de regels bevatten de categorieën;  één transactie kan worden `split_transaction`gesplitst, maar de API van YNAB kan een splitsing niet wijzigen of ongedaan maken | wijzig of maak ze ongedaan in YNAB |
| Suggesties | vereist een geschiedenis: een nooit geclassificeerde handelaar krijgt geen suggesties | de agent doet een voorstel, u beslist |
| Prognose | bouwt voort op de afgelopen maanden, plus de geplande transacties van YNAB; een driemaandelijkse of jaarlijkse afschrijving zonder planning is per definitie geen terugkerende transactie | plan deze in YNAB in, of geef deze door als  `one_offs`|
| Valuta | bedragen worden weergegeven als getallen, zonder valutasymbool | — |
| Python | 3.12 tot en met 3.14; 3.15 wacht op een afhankelijkheid (beartype) | — |

## Roadmap

- Van een document naar de planningen van het jaar: de agent leest een belastingaanslag of
  een voorschotnota, en avenir-mcp maakt de planningen en doelen die daarin staan aan of
  werkt ze bij, in één batch met voorbeeld, bevestiging en ongedaanmaking.
- Een bundel `.mcpb` om met één klik te installeren in Claude Desktop.
- Ongedaan maken voor `update_category`.
- De minimale Python-versie verlagen zodra de afhankelijkheden het toelaten.
- De evaluatie draaien via andere clients dan Claude Code, en met lokale modellen.
