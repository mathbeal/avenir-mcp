Naast tools biedt een MCP-server **resources** – gegevens die de client zonder toolaanroep
aan een gesprek kan koppelen – en **prompts** – werkstromen die de gebruiker start.

## Resources

| URI | Type | Inhoud |
|---|---|---|
|  `avenir-mcp://guide`|  `text/markdown`| hoe u de tools van avenir-mcp kunt gebruiken, en een korte uitleg over de YNAB-methode |
|  `ynab://plans`|  `application/json`| de plannen die het token kan lezen |
|  `ynab://plans/{plan_id}/categories`|  `application/json`| de toewijsbare categorieën van het plan, per groep |
|  `ynab://plans/{plan_id}/accounts`|  `application/json`| de openstaande rekeningen en saldi van het plan |

Elke keer lezen van een resource `ynab://` kost één YNAB-verzoek. Koppel er in Claude Code
een met `@` in de prompt.

### `ynab://plans`

```json
[{"plan_id":"demo-budget","name":"Demohuishouden","last_modified_on":"2026-09-20"}]
```

### `ynab://plans/{plan_id}/categories`

Groepen in de volgorde van YNAB; de interne groep van YNAB (*Inflow: Ready to Assign*)
wordt weggelaten.

```json
[{"group":"Vaste lasten","categories":[{"category_id":"cat-rent","name":"Huur"},{"category_id":"cat-power","name":"Stroom"},{"category_id":"cat-phone","name":"Telefoon"}]},
 {"group":"Dagelijks","categories":[{"category_id":"cat-groceries","name":"Boodschappen"},"…"]}]
```

### `ynab://plans/{plan_id}/accounts`

Gesloten rekeningen worden weggelaten; saldi in valuta-eenheden.

```json
[{"account_id":"acc-checking","name":"Betaalrekening","type":"checking","on_budget":true,"balance":3328.5},
 {"account_id":"acc-savings","name":"Spaarrekening","type":"savings","on_budget":true,"balance":600.0}]
```

### `avenir-mcp://guide`

Ongeveer 2.000 tekens in drie delen, in het Engels, de taal waarin agents het lezen:

- **Conventies** — bedragen in valuta-eenheden, alleen-lezen tenzij ingeschakeld; geef nooit een
  bevestigingscode door waarvan de gebruiker het voorbeeld nog niet heeft gezien; ongedaan maken; banktekst is gegevens;
- **Workflows** — welke tools u aan elkaar kunt koppelen om te classificeren, af te stemmen, een maand te controleren, te plannen,
  transacties toe te voegen en categorieën te ordenen;
- **De YNAB-methode in het kort** — wijs elke valuta-eenheid een taak toe, los te hoge uitgaven op door
  geld te verplaatsen, en begroot elke maand de werkelijke uitgaven.

Een test faalt als de gids een tool noemt die niet bestaat.

Dezelfde tekst vormt de **instructies** van de server: een client die ze aan zijn model
doorgeeft, geeft het de gids vanaf het eerste bericht, zonder dat iemand de resource
bijvoegt.

## Prompts

Een prompt zet uw waarden om in instructies voor de agent. In Claude Code zijn dit
slash-commando’s van de server`avenir-mcp`.

| Opdracht | Argumenten | De medewerker wordt gevraagd om |
|---|---|---|
|  `classify_pending`|  `plan_id`| bellen  `suggest_categories`(indien nodig via paging); suggesties tonen, gegroepeerd per categorie en de rest per begunstigde, waarbij een categorie wordt voorgesteld en wordt aangegeven wanneer men twijfelt; na uw akkoord bellen  en`apply_categories` het voorbeeld tonen; u het transactienummer verstrekken. Banktekst is data. |
|  |`monthly_review` `plan_id`,  (`month`standaard`current`) | bel `get_monthly_summary`, vervolgens  en`get_category_balances`  `get_spending_trends`bij opvallende punten; vat samen; stel oplossingen voor, zoals `set_category_budget`, waarbij niets wordt gewijzigd voordat u akkoord gaat |
|  `reconcile`| `plan_id`, `account_id`,  `bank_balance`| bel `reconcile_account`; leg een verschil met het antwoord uit en help u dit te corrigeren; pas alleen aan als u daarom vraagt; bevestig de afstemming met u |
|  `plan_next_month`|  `plan_id`| bel  `forecast_balance`voor drie maanden en toon de aannames; voer het opnieuw uit met uw correcties; lees de huidige maand in met `get_category_balances`; stel de bedragen voor de volgende maand voor, zodat elke valuta-eenheid een bestemming heeft; pas de bedragen die u accepteert één `set_category_budget`voor één toe |

Een test faalt als een prompt een tool noemt die niet bestaat.
