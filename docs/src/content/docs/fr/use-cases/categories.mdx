**Objectif :** garder une structure de catégories à jour quand votre vie change.

| Demandez | Outil |
|---|---|
| *« Crée une catégorie Animaux dans Everyday. »* | `create_category` |
| *« Renomme Gym en Sport. »* | `update_category` |
| *« Déplace Books de Fun vers Education. »* | `update_category` |
| *« Mets 150 dans Restaurants pour septembre. »* | `set_category_budget` |

Chacun prévisualise le changement et attend votre confirmation. Un nom déjà utilisé dans
le groupe est refusé.

<Code code={budget} lang="json" />

<Aside type="note" title="Supprimer une catégorie">
L'API de YNAB ne permet pas de supprimer une catégorie. Pour annuler une création,
masquez la catégorie dans YNAB.
</Aside>
