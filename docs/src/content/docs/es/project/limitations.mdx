## Limitaciones conocidas

| Área | Limitación | Alternativa |
|---|---|---|
| Códigos de confirmación | se guardan en memoria: un reinicio del servidor los olvida | pedir una nueva vista previa |
| Deshacer | local a la máquina cuyo diario registró la operación; una anulación no se puede anular | rehacer el cambio |
| `approve_transactions` | se aplica al momento, sin vista previa | solo quita la marca de revisión de YNAB |
| `import_transactions` | se aplica al momento, sin vista previa; no se deshace aquí | solo trae lo que el banco ya tiene; borre una transacción en YNAB para revertirla |
| `update_category`, `create_category` | no se pueden deshacer; la API de YNAB no puede borrar una categoría | renombrar de nuevo; ocultar la categoría en YNAB |
| Transporte HTTP | HTTP simple, un solo token compartido, sin cuentas | mantenerlo en `127.0.0.1`, o usar stdio |
| Servidor público o compartido | no compatible: sin cuentas, y las condiciones de YNAB exigen OAuth para planes ajenos | cada persona ejecuta su propio avenir-mcp — vea el [aviso legal](/avenir-mcp/es/project/legal/) |
| Transacciones divididas | nunca se sugieren ni se recategorizan: sus líneas llevan las categorías; `split_transaction` divide una, pero la API de YNAB no puede cambiar ni deshacer una división | cambiarlas o deshacerlas en YNAB |
| Sugerencias | necesitan historial: un comercio nunca clasificado no recibe ninguna | el agente propone, usted decide |
| Previsión | prolonga los últimos meses, más las transacciones programadas de YNAB; un cargo trimestral o anual sin programación no es recurrente según su definición | programarlo en YNAB, o pasarlo como `one_offs` |
| Moneda | los importes se muestran como números, sin símbolo de moneda | — |
| Python | 3.12 a 3.14; 3.15 espera a una dependencia (beartype) | — |

## Hoja de ruta

- De un documento a los vencimientos del año: el agente lee un aviso de impuestos o un recibo de la comunidad de propietarios, y avenir-mcp crea o actualiza los vencimientos y los objetivos que fija, en un solo lote previsualizado, confirmado y reversible.
- Suscripciones y cargos recurrentes, en solo lectura: lo que paga cada mes o cada año, y lo que ha costado.
- Beneficiarios: listarlos, y renombrar una etiqueta bancaria con el nombre del comercio, con vista previa y deshacer.
- Editar una transacción (fecha, importe, beneficiario, memo), una vez decidido si deshacer puede guardar el memo anterior en el diario local.
- Un paquete `.mcpb` para instalar con un clic en Claude Desktop.
- Deshacer para `update_category`.
- Bajar la versión mínima de Python cuando las dependencias lo permitan.
- Ejecutar la evaluación con otros clientes distintos de Claude Code, y con modelos locales.
