## Bekannte Grenzen

| Bereich | Grenze | Umgehung |
|---|---|---|
| Bestätigungscodes | im Speicher gehalten: Ein Neustart des Servers vergisst sie | erneut nach einer neuen Vorschau fragen |
| Rückgängig | auf den Rechner beschränkt, dessen Journal die Operation erfasst hat; ein Rückgängigmachen lässt sich nicht rückgängig machen | die Änderung erneut vornehmen |
| `approve_transactions` | wird sofort angewendet, ohne Vorschau | es entfernt nur das Prüfkennzeichen von YNAB |
| `import_transactions` | wird sofort angewendet, ohne Vorschau; hier nicht rückgängig zu machen | es holt nur, was die Bank bereits hat; eine Transaktion in YNAB löschen, um sie zurückzunehmen |
| `update_category`, `create_category` | nicht rückgängig zu machen; die API von YNAB kann keine Kategorie löschen | zurückbenennen; die Kategorie in YNAB ausblenden |
| HTTP-Transport | einfaches HTTP, ein gemeinsames Token, keine Benutzerkonten | auf `127.0.0.1` belassen oder stdio nutzen |
| Öffentlicher oder geteilter Server | nicht unterstützt: keine Benutzerkonten, und die Bedingungen von YNAB verlangen OAuth für die Plans anderer | jede Person betreibt ihr eigenes avenir-mcp – siehe die [rechtlichen Hinweise](/avenir-mcp/de/project/legal/) |
| Aufgeteilte Transaktionen | nie vorgeschlagen oder neu kategorisiert: Ihre Zeilen tragen die Kategorien; `split_transaction` teilt eine auf, aber die API von YNAB kann eine Aufteilung weder ändern noch rückgängig machen | in YNAB ändern oder rückgängig machen |
| Vorschläge | brauchen eine Historie: Ein nie kategorisierter Händler erhält keinen | der Agent schlägt vor, Sie entscheiden |
| Prognose | schreibt die letzten Monate fort, plus die geplanten Transaktionen von YNAB; eine vierteljährliche oder jährliche Belastung ohne Planung kehrt nach ihrer Definition nicht wieder | in YNAB planen oder als `one_offs` übergeben |
| Währung | Beträge werden als Zahlen gezeigt, ohne Währungssymbol | — |
| Python | 3.12 bis 3.14; 3.15 wartet auf eine Abhängigkeit (beartype) | — |

## Roadmap

- Von einem Dokument zu den Planungen des Jahres: Der Agent liest einen Steuerbescheid
  oder eine Nebenkostenanforderung, und avenir-mcp legt die darin festgelegten Planungen und
  Ziele an oder aktualisiert sie, in einem als Vorschau gezeigten, bestätigten und
  rückgängig zu machenden Stapel.
- Ein Paket `.mcpb` zur Installation mit einem Klick in Claude Desktop.
- Rückgängigmachen für `update_category`.
- Die Mindestversion von Python senken, sobald die Abhängigkeiten es erlauben.
- Die Evaluierung über andere Clients als Claude Code und mit lokalen Modellen ausführen.
