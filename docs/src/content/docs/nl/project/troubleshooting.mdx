## Verbinding

<details>
<summary>Mijn client toont de tools van avenir-mcp niet</summary>

1. Controleer of de server verbonden is: `claude mcp list`, of via het MCP-paneel van uw client.
2. Voer  uit in`uvx avenir-mcp` een terminal. Het programma zou stil moeten wachten op een client; een foutmelding
   die daar wordt weergegeven, is dezelfde die door uw client wordt verborgen.
3. Start de client opnieuw op nadat u de configuratie ervan hebt aangepast.
4. Controleer of  `uv`zich bevindt op de  die uw`PATH` client ziet. Grafische toepassingen zien mogelijk de
    van`PATH` uw shell niet: geef het volledige pad naar  op in`uvx` de configuratie.

</details>

<details>
<summary>De tools die mijn plan wijzigen ontbreken</summary>

avenir-mcp is alleen-lezen, tenzij de omgeving precies  `AVENIR_MCP_WRITE=1`— bevat`1`.
Start de server opnieuw op nadat u dit hebt gewijzigd.

</details>

<details>
<summary><code>ModuleNotFoundError: avenir_mcp</code> in een map die iCloud Drive synchroniseert</summary>

iCloud kan bestanden als verborgen markeren, en recente Python-versies slaan verborgen
`.pth`-bestanden over, wat bewerkbare installaties breekt. Houd de virtuele omgeving buiten
de gesynchroniseerde map: `UV_PROJECT_ENVIRONMENT=~/.local/share/avenir-mcp/venv uv sync`.

</details>

## YNAB

<details>
<summary><code>YNAB 401</code></summary>

Het token is verkeerd of is ingetrokken. Maak een nieuw aan in de Developer Settings van
YNAB en werk `YNAB_API_KEY` bij.

</details>

<details>
<summary><code>YNAB 404</code></summary>

Een plan, rekening, categorie of maand die YNAB niet kent. Id's komen uit `list_plans`,
`list_accounts`, `list_category_groups` of `get_category_balances`; maanden moeten in het
plan bestaan.

</details>

<details>
<summary><code>YNAB 429</code></summary>

De 200 verzoeken per uur zijn op. Wacht een paar minuten; latere aanroepen zijn goedkoop
dankzij delta-synchronisatie. Zie
[Gegevens en synchronisatie](/avenir-mcp/nl/concepts/data-and-sync/#de-verzoeklimiet-van-ynab).

</details>

## Schrijfacties

<details>
<summary>De agent blijft <code>confirmation_required</code> antwoorden</summary>

Uw klant kan geen bevestigingsvenster weergeven, dus heeft avenir-mcp een voorbeeld en een code teruggestuurd.
Laat de medewerker weten dat u akkoord gaat: hij belt opnieuw met de code. Een code is 10 minuten geldig en werkt
één keer; vraag na een herstart van de server om een nieuw voorbeeld.

</details>

<details>
<summary><code>The plan changed between the preview and the answer</code></summary>

Er is iets veranderd aan een transactie tussen het voorbeeld en uw antwoord — door u in YNAB, een
import of een andere gebruiker. Vraag het nogmaals: het nieuwe voorbeeld geeft de huidige stand van zaken weer.

</details>

<details>
<summary><code>Nothing to undo</code></summary>

Geen enkele operatie van dit plan is nog van kracht in het journaal van deze computer: ze
is al ongedaan gemaakt, elders gedaan, of het journaalbestand is veranderd. Zie
[Journaal en ongedaan maken](/avenir-mcp/nl/concepts/journal/).

</details>

## Diagnose

<details>
<summary>Waar zie ik wat de server doet?</summary>

Stel in  `AVENIR_MCP_LOG_LEVEL=INFO`(elke oproep en elk verzoek) of  `DEBUG`(alles).
Diagnostische gegevens worden naar stderr gestuurd, die uw client in zijn MCP-logbestanden bewaart — in Claude Code
`claude --debug`worden deze weergegeven. stdout behoort tot het protocol.

</details>

Elke melding die een tool kan teruggeven, staat in de
[foutencatalogus](/avenir-mcp/nl/reference/errors/).
