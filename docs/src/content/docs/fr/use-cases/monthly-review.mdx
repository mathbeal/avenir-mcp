import { Code, Steps } from '@astrojs/starlight/components';
import summary from '@snippets/monthly_summary.json?raw';
import balances from '@snippets/category_balances.json?raw';
import budget from '@snippets/budget_preview.json?raw';

**Objectif :** comprendre où est passé l'argent et corriger ce qui a dérapé.

**Demandez :** *« Fais le point sur septembre avec moi. »* — ou lancez le prompt
`monthly_review`.

<Steps>

1. **`get_monthly_summary`** donne le mois en un coup d'œil — revenus, budgété, dépensé,
   Ready to Assign — et seulement les catégories en dépassement :

   <Code code={summary} lang="json" />

2. **`get_category_balances`** et **`get_spending_trends`** expliquent ce qui ressort :
   les restaurants sont-ils élevés ce mois-ci, ou tous les mois ?

   <Code code={balances} lang="json" />

3. Claude propose des corrections — le plus souvent, déplacer de l'argent d'une catégorie
   qui a de la marge vers celle qui dépasse — et les applique avec
   `set_category_budget` une fois que vous êtes d'accord :

   <Code code={budget} lang="json" />

</Steps>

Un dépassement se corrige en déplaçant de l'argent entre catégories, pas en l'ignorant :
c'est la méthode YNAB, que la ressource `avenir://guide` rappelle aux agents. Les
catégories sans rien de budgété, dépensé ni disponible sont écartées, sauf si vous
demandez `include_empty`.
