<Aside type="caution" title="Sin relación con YNAB">
YNAB y You Need A Budget son marcas registradas de YNAB. Avenir es un proyecto
independiente que usa la API pública de YNAB con tu propio token de acceso. *Avenir*
significa *el futuro* en francés.
</Aside>
