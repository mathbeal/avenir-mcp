## Why Avenir

<CardGrid>
  <Card title="Tools for tasks, not endpoints" icon="rocket">
    Classify a month of transactions, reconcile an account with the bank, forecast the
    balance, review a month: each is one tool, not ten API calls for the agent to chain.
  </Card>
  <Card title="Read-only by default" icon="seti:lock">
    The eight write tools are neither listed nor callable until you set
    `AVENIR_MCP_WRITE=1`. An agent cannot change what it cannot see.
  </Card>
  <Card title="Answers an agent can read" icon="document">
    Currency units, never milliunits. Typed output schemas with a description for every
    field, pagination, and errors that say what to fix.
  </Card>
  <Card title="Light on YNAB's quota" icon="seti:clock">
    A local copy of your transactions, refreshed by delta sync: most tools cost one or
    two of the 200 requests YNAB allows per hour.
  </Card>
</CardGrid>

## Every change, on your terms

<WriteFlow />

Categories, amounts, reconciliations and created transactions can all be undone. How it

## Real answers, not prose

Tools return structured data the agent can rely on. Asked how September is going, the
agent calls [`get_monthly_summary`](/avenir-mcp/reference/tools/get-monthly-summary/)
and gets the month's totals and only the categories that need attention:

Every example in this documentation is a real answer from Avenir on an invented demo
budget.
