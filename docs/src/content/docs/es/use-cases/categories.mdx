| Pide | Herramienta |

Cada una previsualiza el cambio y espera tu confirmación. Un nombre ya usado en el grupo
se rechaza.

<Aside type="note" title="Eliminar una categoría">
La API de YNAB no permite eliminar categorías. Para deshacer una creación, oculta la
categoría en YNAB.
