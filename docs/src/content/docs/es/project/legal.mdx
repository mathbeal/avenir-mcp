## Para qué está pensado avenir-mcp

avenir-mcp está pensado para un **uso personal**: una persona lo ejecuta **en su propia
máquina**, con **su propio token de YNAB**, para sus propios presupuestos.

<Aside type="caution" title="No compatible: un servidor público o compartido">
Ejecutar avenir-mcp como servidor MCP público o compartido — alojarlo para otras personas,
exponer su transporte HTTP en Internet o recoger tokens de YNAB de otras personas — **no
es un uso previsto** y no está soportado:

- las condiciones de la API de YNAB reservan el token de acceso personal a su titular;
  una aplicación usada por otros debe usar OAuth, con una política de datos publicada.
  avenir-mcp no tiene ni lo uno ni lo otro;
- avenir-mcp no tiene cuentas de usuario ni aislamiento entre usuarios, y su transporte HTTP
  está hecho solo para esta máquina.

Hacerlo sería bajo su propia responsabilidad, y podría infringir las condiciones de YNAB.
</Aside>

## El Reglamento europeo de IA (AI Act)

avenir-mcp no contiene **ningún modelo de IA**. Sus sugerencias cuentan qué categorías recibió
antes un beneficiario; sus previsiones usan medianas y medias. Es una herramienta a la
que llama un agente de IA, no un sistema de IA en sí. El sistema de IA es su cliente MCP
y su modelo, cuyo proveedor — Anthropic, OpenAI, Google u otro — asume las obligaciones
del Reglamento (UE) 2024/1689. Usarlo para su propio presupuesto es un uso puramente
personal y no profesional, y avenir-mcp se publica bajo licencia libre. No evalúa la
solvencia de nadie, el uso ligado al crédito que el reglamento clasifica como de alto
riesgo.

Es la lectura del editor, no un asesoramiento jurídico. Una versión alojada y comercial
que integre un modelo requeriría un nuevo análisis.

## Adónde van sus datos

- avenir-mcp solo envía sus datos de presupuesto a **YNAB** y al **proveedor del modelo** que
  usa su cliente MCP (ninguno, con un [modelo local](/avenir-mcp/es/guides/choose-a-model/#modelos-locales)).
- Quien publica avenir-mcp no recibe **nada**: ni telemetría, ni cuenta, ni servidor.
- Este sitio de documentación no instala **ninguna cookie** ni hace **ninguna medición
  de audiencia**; sus fuentes las sirve el propio sitio.
- Qué se conserva, durante cuánto tiempo y cómo borrarlo: consulte [Privacidad](/avenir-mcp/es/project/privacy/).
